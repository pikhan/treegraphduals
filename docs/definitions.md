# Working definitions

The definitions the library implements and the tests check. When code, a test, an
issue and a paper disagree, this page wins. A change of definition goes through a
PR, and through an ADR in `docs/adr/` when it settles a convention.

Each entry gives its **source** (thesis or paper) and the **definition** as the
library uses it. Note where the working definition deliberately differs from the
source.
